# 活字排版工坊

一个纯前端本地应用，用来维护字模库位台账、在网格版面中落字、按已用字生成取字单、保存草稿并导出 PNG 预览图。所有数据只存浏览器（localStorage），不上传任何服务器。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 库位台账

- 每个字模登记 **柜号 / 层号 / 格号**，字模卡上显示「几柜几层几格 · 本格 X/3 枚」。
- **同一格（同柜同层同格）合计不超过 3 枚**：登记新字模或调整库位时，若该格枚数超限，拒绝入位并说明原因。
- 字模卡上可随时「补录 / 调整」库位。

## 落字规则

- 选中字模后点击版面格子落字，再点同字擦除；也可拖拽字模到版面。
- **缺库位**（换柜架后未补录的旧字模）或**库位超容**时，当前格子不许落字，已在格子里的字也不会被替换；原因显示在字模卡与版面上方提示条中。

## 取字单

- 根据版面已用字生成，**同一柜层合并枚数**，再按 **柜号 → 层号 → 格号** 排列；缺库位的字单列在末尾。
- **调整库位不动已落字**：落字时记录库位快照，之后台账改了库位，对应格子与取字单项标记「待复核」。

## 旧字模与草稿

- 缺库位的旧字模**留库待补录**（字模卡标黄），补录后即可正常落字。
- 草稿保存在本地，载入旧草稿时，落字库位与现台账不符的项同样在取字单中标记待复核。
