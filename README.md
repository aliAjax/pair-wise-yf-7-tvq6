# 活字排版工坊

一个纯前端本地应用，用来维护字模库与库位台账、在网格版面中落字、按版面生成取字单、保存草稿并导出PNG预览图。数据只保存在浏览器 localStorage，不上传任何服务器。

## 库位台账

- 每个字模登记柜号、层号、格号；同一柜/层/格合计不超过 3 枚。
- 未登记库位或所在位置超容的字模不可落字，字模卡上会标明原因（待补录 / 超容）。
- 字模卡上的「调库位」可改柜、层、格与数量，也可清除库位留库待补录。
- 调整库位不动已落字；若该字模已上版，取字单会把它标记为「待复核」，复核后可清除标记。
- 「库位台账」页签按柜、层、格列出每个位置的合计枚数，超容位置红色高亮。

## 取字单

- 按版面已用字自动生成：同一柜层合并枚数，组间按柜号、层号排列，组内按格号排列。
- 缺库位的已用字单列「缺库位 · 待补录」组；取用超过存量的行会红色示警。

## 留库待补录

- 缺库位的旧字模保留在字模库中，可用筛选器只看「待补录」或「超容」。
- 已保存草稿照常留库；含缺库位字模的草稿会标注提示。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
